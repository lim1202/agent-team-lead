# 实验证据摘要

证据等级：**源码核对**证明机制存在；**本地记录**证明历史记录中存在该事实，不等同于独立重演；**隔离验证**证明合成环境中的行为；复盘文字不能单独升级为端到端保证。证据核对阶段未重跑业务测试、外部评审或真实通知。

| 观察 | 证据与差异 | 设计启示 |
| --- | --- | --- |
| 持久任务资产、原会话返修和独立验收可用 | 两组均有任务、候选和验收记录；A 两任务四类报告的登记摘要均与报告字节一致；B 交付摘要与验收绑定一致，有 27 项内容覆盖核对记录 | 保留 task/session/run/candidate 分层身份；交回结果不自动完成 |
| 脚本采样与事件推送可替代常态模型巡检 | 两组源码均有独立 watcher、本地摘要、queue 和显式 ack；A 保存 117 项已发送记录，但无法由此推算消费次数；B 探针绑定目标、nonce 和确认时间，约 31 分钟后确认 | 常态检查不调用模型；只对可处理事件唤醒；不承诺即时或恰好一次 |
| A 的监控不是可原样复制的可靠队列 | `update` 每任务只保留一个 pending，新快照会覆盖未 ack 事件；此前合成调用已重现 approval→working 后旧 signal 消失。done 还会产生待验收通知 | 观察快照与待处理事件分开；保留所有未处理异常；空闲只记活动，不生成交付事件 |
| B 保留 deferred，但仍有降噪缺口 | 源码保存未处理旧事件；权限拒绝按工具 ID 区分，语义相同的新请求仍可能反复唤醒 | 保留 deferred 思路，增加同一阻塞周期的聚合；这是新增设计，尚未经实验验证 |
| 监控与开发恢复必须分开 | A 有原会话退出后 attach、PID 更新的任务记录及热加载修复提交；B 有同 session、新 run 的 runner 和结果记录。A 守护仅恢复 watcher；B 隔离测试实际恢复替身 watcher | 守护不重启开发进程；Leader 核对后才能接续原会话，并确认恢复后确实继续执行 |
| 权限授权与工具许可是两层 | A 记录原界面启用 auto，后因已授权外发仍被拒绝，降为 acceptEdits + 本 worktree 精确脚本规则；B 无审批界面，拒绝就是未执行，常可用原生读取或单独命令替代 | 优先使用实际可用的自审批，但不把 auto 等同所有操作已获业务授权；先用已许可替代入口，越界才请求用户 |
| 权限配置不是完整运行事实 | A 静态预检仅查部分配置，不能模拟权限引擎；权限历史字段仍写 auto，与后续降级记录不一致。B 最终 runner 参数可由源码还原，但不会追溯约束旧进程 | 每次运行记录实际版本、模式、策略摘要和生效时间；策略改变不伪称在途进程已生效 |
| 无输出、退出码和评审标签不足以验收 | B 历史结果含 exit=0 且 is_error=true，也有超时；两组均出现长评审、部分报告和无意义重复重评 | 检查最终结果、交付身份、候选内容、有效覆盖和真实测试；疑似停滞只诊断，不杀进程 |
| 收尾也有状态不一致 | A 两任务记录均已关闭，但监控快照一项仍未关闭，旧健康快照仍为健康；B 有 watcher、健康作业及 hook 清理记录 | 完成前对账任务记录、实时进程、后台服务和清理清单；历史健康文件不能证明当前健康 |

可复用的成功做法：范围化授权、隔离工作树、共享资源串行、失败带证据交回原会话、按内容绑定评审、独立验收及精确清理。应放弃高频模型巡检、working/done 即进展/完成、每次权限拒绝都向用户升级、无限全量评审、任意放行 Shell、重复 attach 不回收。

证据核对阶段运行 A 监控 31 + 守护 5 项、B runner 59 + 一次性交接 hook 3 项，全部通过。hook 能按 session/run/策略摘要隔离传递上下文，是否使用在途 hook 由执行路径的实际需要决定。测试覆盖模拟通知与隔离进程，不证明真实网络故障、宿主重启、额度耗尽后自动推进或横幅可见性。没有可靠成本对照，不能声明节省比例。

## 使用边界

以上为两个实验的证据摘要，不代表本仓库已有可安装实现。审批降噪、通用交接以及不同 Leader 宿主的能力仍须实测。特定实验的运行模式、采样间隔和返修轮数不作为通用要求。首版设计见 [设计评审稿](v0-design.md)。
